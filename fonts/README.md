# Built-in CJKV Fonts

Open source fonts bundled into this image.

Included:

- Noto Sans CJK
- Noto Serif CJK
- HanaMin A/B
- Jigmo


Purpose:

- Chinese / Japanese / Korean rendering
- Unicode CJK Extension coverage
- Traditional and rare Han character support
